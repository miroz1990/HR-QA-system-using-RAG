TechNova Inc. - IT Security Policy
Version: 2.5
Last Updated: February 2026

1. Password Policy
1.1 Passwords must be at least 8 characters long.
1.2 Passwords must be changed every 90 days.

2. Data Protection
2.1 Employees must not share sensitive data without authorization.
2.2 Data must be stored only on approved systems.

3. Device Usage
3.1 Company devices must be used for work purposes only.

4. Security Incidents
4.1 Any suspected breach must be reported immediately.

5. Remote Access
5.1 Remote access must comply with security protocols defined in this policy.
